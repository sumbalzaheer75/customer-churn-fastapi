PART B — DEPLOY ON RENDER
The files are prepared for Render, but the app is not deployed until you upload them to a GitHub repository and create a Render Web Service.
1. Create a NEW public GitHub repository named customer-churn-fastapi (or another name you prefer).
2. Upload the project files from the folder, including churn_pipeline.pkl and index.html. Do NOT upload .venv or private/customer source data. Because .python-version and .gitignore start with a dot, make sure you add them too.
3. On https://render.com/, sign in and connect GitHub. Create a new Web Service and select your new repository.
4. Use these settings if Render does not read render.yaml automatically:
   Runtime: Python 3
   Build command: pip install -r requirements.txt
   Start command: uvicorn app:app --host 0.0.0.0 --port $PORT
   Plan: Free, if available in your account.
5. Deploy. Once successful, test the URL ending in /, /health, and /docs.

Do not share this app as a production service or use real customer personal data. This is a learning/demo project and churn scores are model estimates.
